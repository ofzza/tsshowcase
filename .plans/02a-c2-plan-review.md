## Refuted

- **F9** (`import pkg from '../../package.json'` breaks the composite build): **refuted by experiment** (TS 6.0.3, `composite`, `rootDir: src`). It builds cleanly, and the emitted import resolves to the package's `package.json` at runtime because `src/` and `dist/` sit at the same depth. Vite handles the JSON import in browser bundles. No change.
